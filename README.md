## Sobre o projeto
Este projeto foi desenvolvido como atividade acadêmica para praticar os conceitos de Programação Orientada a Objetos, utilizando classes, herança e sobrescrita de métodos em Java.

## Classes desenvolvidas
- Funcionario: representa um funcionário e calcula seu salário-base.
- Desenvolvedor: herda de Funcionario e recebe um adicional de R$ 500 por projeto concluído.
- Gerente: herda de Funcionario e recebe um adicional de R$ 1.000 por equipe gerenciada.

## Tecnologias
- Java
- Programação Orientada a Objetos
- UML
